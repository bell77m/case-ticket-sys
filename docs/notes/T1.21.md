# T1.21 CI pipeline, part 1

Date: 2026-09-28 · Requirements: none (ops) · Agent: ops

## What was done
- CI on GitHub Actions (`.github/workflows/ci.yml`) runs on every pull request and on every push to `main`. It runs lint, tests with a 70% coverage gate, the i18n check, Gitleaks, Semgrep, govulncheck and a Trivy filesystem scan. The full Playwright suite was added on 2026-09-28; see the [CI/CD note](2026-09-28-ci-cd.md).
- The done criterion is proven on GitHub:
  - A pull request from branch `ci/t1-21-planted-secret` added `ci-canary/planted-secret.txt` with a fake GitHub token (commit b8e9ae5, "Never merge. The token is fake."). The branch was `ci/github-actions-cd` plus that one commit.
  - The Gitleaks step failed the run: "leaks found: 1", rule `github-pat`, file `ci-canary/planted-secret.txt` line 3, "6 commits scanned", "Process completed with exit code 1".
- After the run, the canary branch was deleted locally and on GitHub, so GitHub closes its pull request without merging.

## Files
- docs/PLAN.md: T1.21 ticked.
- PROGRESS.md: T1.21 blocker resolved, log line added.
- docs/notes/T1.21.md: this note.
- The canary file existed only on the deleted branch. `ci.yml` itself was written earlier: on 2026-09-23 (T1.21 part 1) and on 2026-09-28 (the CI/CD note).

## Decisions
- **Evidence.** The CI result was taken from the run log the user pasted, because the repo is private, the `gh` CLI is not installed, and the public API answers "Not Found". Two facts show the run was a pull-request run: ci.yml triggers only on `pull_request` and on push to `main`, and the canary commit was on no branch except its own. To confirm by hand, open the Actions tab and filter by the closed pull request.
- **Where the tick lives.** T1.21 is ticked on branch `ci/github-actions-cd`, where the CI work is, so it reaches `main` when that branch merges.

## Checks
- Run log from the user (GitHub Actions, step "Gitleaks (secrets in code or history)", gitleaks v8.24.2): 1 leak found, exit code 1.
- `grep continue-on-error .github/workflows/ci.yml`: no matches, so the failing step fails the job and the run.
- `git merge-base --is-ancestor b8e9ae5 <branch>`: `main`, `origin/main` and `ci/github-actions-cd` do not contain the canary commit. Before deletion, `git branch -a --contains b8e9ae5` listed only the canary branch and its remote.
- `git show b8e9ae5:ci-canary/planted-secret.txt`: the file says the token is fake and starts `ghp_T121…`.
- `git push origin --delete ci/t1-21-planted-secret`: `- [deleted]`.
- Not checked here: whether the other CI jobs (tests, lint, e2e) passed on that pull request, since the result could not be read without `gh`.
